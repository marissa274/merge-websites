# Personal portfolio template

Independent portfolio, built with vanilla HTML/CSS, Motion and esbuild. No backend or tracking.

- `npm install` then `npm run build`
- `npm run dev` → http://127.0.0.1:4174/
- Edit `dist/index.html` for identity, services and contact copy.
- Edit project information in `src/app.js`, then rebuild.
- Edit design tokens in `dist/tokens.css`.
- All displayed projects are original demonstration concepts, not client work.
- Contact form only prepares a local draft. Connect a real email/form integration before selling or publishing as a finished personal website.
- Replace Your Name, Your city, project descriptions, page metadata and favicon before delivery.
- Keep reduced-motion support, keyboard focus and local message privacy intact.

No publication or Git commit is part of this build.

## Distribution

Font and bundled Motion notices are preserved in `dist/licenses/`. Keep these notices when redistributing. The ZIP contains source and built assets, without node_modules.
